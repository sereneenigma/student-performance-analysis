# Student Data Analysis

A beginner-friendly project to analyze student data using Python, Pandas, and NumPy.

## Libraries Used
- Python
- Pandas
- NumPy

## How to Run
1. Install required libraries:
   pip install pandas numpy
2. Run the script:
   python student_analysis.py

## Description
This project demonstrates basic data analysis and visualization on student data.
